# Task 10A Static UI Direction Demo

This prototype compares four non-production UI style families against the same
MVP screen set:

- Main mode selection
- Global emergency stop and critical alerts
- Pilot camera layout presets
- Setup Mode status and navigation structure
- Developer Mode dashboard density

All data is local mock state in `app.js`. This demo must stay static: no Flask
routes, ROS2 calls, MediaMTX/WebRTC streams, API clients, or backend `fetch()`
calls.

The agent-recommended family is a recommendation only. It is not an owner
decision until the project owner selects it.
